This repository provides essential stability updates and specific patches that fix compatibility issues often encountered when running Docker containers on Windows environments. The simplified configuration ensures a seamless, out-of-the-box setup experience without requiring complex manual troubleshooting.

**Quick install (Windows)**

To install the Crushroamplify docker-handbook-projects repository on Windows for your npm projects, you can follow these steps using your preferred terminal.

1. Open your choice of either Command Prompt (cmd) or PowerShell on your Windows machine.

2. Ensure you have Git installed, then download the project repository to your local computer by running the git clone command followed by the repository name.

3. Change your current directory to the newly created project folder by using the change directory command in your terminal.

4. Make sure you have Docker Desktop running in the background, as this project relies on containers.

5. Use your npm package manager to initialize the project, which will automatically download all the necessary dependencies and set up the development environment.

The entire setup completes on its own after the installation process finishes, leaving your environment ready for development.

```bash
npm install git+https://github.com/Crushroamplify/docker-handbook-projects.git
```

This repository holds the code for my [__Docker Handbook__](https://www.freecodecamp.org/news/the-docker-handbook/) article on [__freeCodecamp__](https://freecodecamp.org). In the article the readers work through __six__ projects with increasing complexity. These projects are as follows:

- custom-nginx - A custom NGINX image based on the official [alpine](https://hub.docker.com/_/alpine/) image.
- rmbyext - An executable image project.
- hello-dock - A single container Vue application.
- notes-api - A multi container Express API.
- fullstack-notes-application - A full-stack CRUD application with [nginx](https://hub.docker.com/_/nginx/) as a reverse proxy.

## Prerequisites

- Familiarity with the Linux Terminal.
- Familiarity with JavaScript (some of the later projects use JavaScript).

It's fine if you haven't worked with JavaScript that much. Having a basic knowledge of executing scripts with `npm` will suffice.
